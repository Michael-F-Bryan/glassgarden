# Glassgarden

An aquarium idle game about nurturing a living ecosystem that grows and evolves in response to the player.

## Development

```sh
npm install
npm run dev
```

The app uses Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Checks

```sh
npm test
npm run lint
npm run typecheck
npm run build
```
